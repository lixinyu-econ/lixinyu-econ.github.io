This is the first post on my new site. I'll use this space to write about my research, share notes from the archive, and reflect on teaching.

To write a new post, add a Markdown file to the `_posts` folder named `YYYY-MM-DD-short-title.md`, starting with a header like the one at the top of this file. GitHub will rebuild the site automatically within a minute or two.

## Formatting examples

You can use *italics*, **bold**, and [links](https://example.com). Block quotes work well for archival material:

> "An example quotation from a primary source, with its citation below."
> — Author, *Title* (1885), p. 12

Footnotes are supported too.[^1]

[^1]: Like this one. They appear at the bottom of the post.
